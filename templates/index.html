How It Works

01

High-Pass Filtering

A fixed KV kernel suppresses image content and amplifies microscopic noise residuals where hidden bits live.

02

Deep Feature Extraction

Four convolutional blocks with BatchNorm and Average Pooling aggregate noise statistics across the full image.

03

Binary Classification

Global Average Pool + Dropout + FC layer outputs a confidence score: Cover vs. Stego.

What Is LSB Steganography?

Steganography hides secret information inside ordinary files. In LSB image steganography, data is concealed by altering the Least Significant Bit of pixel values — a change completely invisible to the human eye but detectable by AI.

StegoDetect uses a SRM-style high-pass filter inspired by XuNet, trained on the BOSSbase dataset with 20% payload LSB injection.
